# 搜索意图（Search Intent）

> 摘要：用户搜一个词，背后是想"了解 / 找网站 / 比价 / 下单"。搞清意图，才知道该做哪种页面。

## 什么是搜索意图

同一个词，目的天差地别。比如搜"iPhone 15"：

- 想**了解**参数 → 信息意图
- 想**进官网** → 导航意图
- 想**比价格 / 看评测** → 商业意图
- 想**直接买** → 交易意图

搜索引擎的核心目标，是把"最能满足这次搜索意图"的页面排前面。所以**你的页面形态必须匹配意图**，否则再相关也排不上去。

## 四种意图

| 类型 | 用户想干嘛 | 该做什么页面 | 例子 |
|---|---|---|---|
| **信息型 Informational** | 学东西、查答案 | 博客 / 教程 / 指南 | "怎么给照片去背景" |
| **导航型 Navigational** | 找某个特定网站 | 官网首页 / 品牌页 | "微信登录" |
| **商业型 Commercial** | 买前做功课 | 评测 / 对比 / 榜单 | "最佳去背景工具" |
| **交易型 Transactional** | 直接行动 | 产品页 / 注册页 | "去背景工具 订阅" |

## 怎么判断一个词的意图

最靠谱的方法：**亲自搜一下，看排在前面的都是什么页面**。

- 前面全是教程 → 这个词要的是信息页。
- 前面全是产品/定价 → 要的是交易页。
- 意图和你做的页面类型对不上，说明你选错了页面形态，不是内容不好。

> 这就是"SERP 研究"——动手看谷歌已经替你选了什么，比任何猜测都准（详见 [`30-content/serp-research.md`](../30-content/serp-research.md)）。

## 进阶：Last-Click（最后一次点击）

saas-seo-playbook 提出一个很有用的视角：**用户转化前最后一次点击落在哪个页面，那个页面就最值钱**。

- 一个典型路径：博客（科普）→ 对比页（选型）→ 产品页（下单）。
- 流量最大的可能是博客，但**真正带来转化的常是靠近交易的页面**。
- 所以分配精力时，别只追"流量大"的词，要看这个词在转化路径上的位置。信息词负责拉新，商业/交易词负责收口。
