# 高权重外链白嫖（作者自有打法）

> 摘要：作者实战验证过的一类"几乎免费、且来自高 DR 平台"的外链来源——把你的项目变成数字资产，让平台自然替你产生链接。

## 核心思路

与其去求别人换链，不如**把你的东西放进本身就高权重、且会展示链接的平台**。这些链接通常是 dofollow 或高曝光，且是"真实存在"的资产，长期稳定。

## 几条已验证 / 常被忽略的路

| 平台类型 | 例子 | 为什么值钱 |
|---|---|---|
| 代码托管 | GitHub 项目 README、仓库主页 | DR 极高，README 里的链接长期稳定 |
| 插件 / 扩展商店 | Chrome / Edge 扩展、VS Code 插件 | 商店页本身高权重，且在多处被索引 |
| 包管理器 | npm / PyPI 等 | 包主页、依赖页会带链 |
| 文档 / 模板平台 | Notion 公开页、公开模板 | 被大量用户复制传播，链接自然扩散 |
| 产品榜单 / 目录站 | 行业导航站、AI 工具导航 | 相关性强，且常是编辑性收录 |

> 注意：具体每条路的"是否 dofollow、当前是否仍有效"会随时间变，作者在自己的库里有逐条实测状态记录。本库只给思路框架，实操前请自行核实当下规则。

## 为什么这招适合独立开发者 / 小团队

- **零预算**：不用买，不用求。
- **复利**：资产一旦发布，链接持续存在并可能被二次引用。
- **相关性强**：你发布的是和你产品相关的真实项目，链接上下文天然相关。

## 配套提醒

- 这些链接再好，也只是"基础信任层"。要冲高竞争词，仍需要编辑性、相关站的真心推荐（见 [`what-links-work.md`](./what-links-work.md)）。
- 别为了凑平台而做一堆没用的"假项目"，谷歌越来越能识别低质数字资产。
