# 链接建设基础

> 摘要：外链（别的网站链你）是搜索引擎判断"谁更可信"的主要信号。链接建设 = 合法地获得高质量外链。

## 为什么外链这么重要

回到排名的两大主轴：**相关 + 可信**。相关靠内容，可信很大程度靠外链——因为"别人愿不愿意链你"是最难造假的可信度信号。一个来自权威、相关站点的链接，相当于它给你的页面投了一票。

## 几个关键概念

- **dofollow / nofollow**：默认链接传递权重（dofollow）；`rel="nofollow"` 告诉谷歌"别把权重传过去"。但 nofollow 仍有价值（真实点击、品牌、二次引用）。
- **链接的"投票力"取决于来源页本身的权重和相关性**：一条来自顶级行业站的相关链接，抵得上一千条垃圾论坛签名。
- **锚文本**：链接上的文字。自然、多样最好；如果所有外链锚文本都精确匹配关键词，反而像操纵，有风险。

## 核心原则

> **赢得链接，而不是买到/骗到链接。** 黑帽手法（买链、PBN、群发）短期可能有效，一旦被识别会降权甚至除名，且难恢复。
