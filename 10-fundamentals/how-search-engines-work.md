# 搜索引擎是怎么工作的

> 摘要：搜索引擎分三步——**抓取（发现）→ 索引（收录）→ 排名（排序）**。你做 SEO，本质就是配合这三步。

## 第一步：抓取（Crawling）—— 发现你的页面

搜索引擎有自动程序叫 **爬虫 / 蜘蛛（crawler / spider / bot）**，顺着网页之间的链接，不断发现新页面。

- 爬虫从一批已知页面出发，读取页面内容，发现里面的链接，再跳到那些链接继续读。
- 你的页面要能被发现，要么被其他已被抓取的页面链到，要么你主动提交（如 sitemap、Google Search Console 提交网址）。
- 如果 `robots.txt` 禁止抓取、或页面被设为 `noindex`、或没人链你，爬虫可能永远到不了你。

## 第二步：索引（Indexing）—— 收录进数据库

抓到的页面，搜索引擎会解析、理解，然后存进自己的超大型数据库，这就是"被收录"。

- 只有被收录的页面，才有可能出现在搜索结果里。**没收录 = 不可能有排名**。
- 常见问题：内容重复被判定为"低价值"不收录、渲染依赖 JS 导致爬虫读不到文字、被 canonical 指到别的页面等。

## 第三步：排名（Ranking）—— 决定谁排前面

用户一搜索，搜索引擎从索引里挑出相关页面，按一套算法排顺序。核心就两件事：

1. **相关性（Relevance）**：这页是不是在回答用户这个问题？（看内容、标题、关键词、意图匹配）
2. **权威 / 质量（Authority / Quality）**：同样相关的多个页面里，谁更可信？（很大程度看外链、内容深度、E-E-A-T）

再加上**用户体验信号**（页面速度、移动友好、是否安全 https 等）和**个性化因素**（用户所在地区、语言、历史）。

> 给新手的提醒：算法有几百个因子，但主轴永远是"**相关 + 可信 + 体验好**"。别去钻某个因子的空子。

## 个性化（Personalization）

同样的词，不同人搜出来的结果可能不同，因为搜索引擎会结合你的地理位置、搜索历史、设备来微调。所以你用自己的电脑看到的排名，不等于全国/全球用户看到的。判断排名要用无痕模式或专业工具（见 [`60-technical/seo-tools.md`](../60-technical/seo-tools.md)）。

## 这对 SEO 意味着什么

把三步倒过来看你的工作：

- **抓取**：确保网站结构清晰、有内部链接、提交 sitemap，让蜘蛛来得了。
- **索引**：确保重要页面能被收录（不误加 noindex）、内容原创有价值。
- **排名**：做好关键词匹配（内容）、积累外链与信任（权威）、优化体验（技术）。
