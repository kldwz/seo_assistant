# 标题层级与关键词自然植入

> 摘要：用 H1~H6 把页面结构讲清楚，让搜索引擎和用户都一眼看懂；关键词要自然出现，不是硬塞。

## 标题层级（Headings）

- **H1**：页面主标题，一个页面只有一个，概括这页讲啥，含主关键词。
- **H2/H3…**：分节小标题，组织内容逻辑，像大纲一样。
- 好处：用户扫读快；谷歌借标题理解内容结构和重点。

写法：

- 小标题要"像人问的问题/关心的点"，而不是堆关键词。
- 层级别跳级（H1 下直接 H3 会乱），保持逻辑嵌套。

## 关键词怎么放

现代 SEO 不靠堆，而靠"在**该出现的地方**自然出现"：

| 位置 | 是否该放 |
|---|---|
| 标题标签 / H1 | 放主词 |
| 开头第一段 | 自然带出主词 |
| H2 小标题 | 可放相关词/长尾 |
| 正文 | 自然出现几次即可，读着顺 |
| 图片 alt | 描述性文字里带词 |
| URL | 含主词（见 [`tdk.md`](./tdk.md)） |

> ❌ 避免：同一句反复塞词（keyword stuffing），读起来像机器人。这会被判作弊。
