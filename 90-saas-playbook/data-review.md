# 从收录到转化：SEO 数据复盘

> 摘要：SEO 不是发了页面就完事。要顺着"收录 → 排名 → 点击 → 转化"漏斗看数据，才知道哪里卡住、该优化哪。

## 漏斗与对应指标

| 阶段 | 看什么 | 常用工具 |
|---|---|---|
| 收录 | 哪些页被索引、哪些被排除 | GSC 覆盖率报告 |
| 排名 | 目标词排第几、涨跌 | GSC 表现 / Ahrefs |
| 点击 | 展示量、点击率 CTR | GSC 表现 |
| 互动 | 停留、跳出、页面深度 | GA4 |
| 转化 | 注册 / 付费 / 留资 | GA4 转化目标 |

## 怎么用漏斗定位问题

- **没收录** → 技术/可达问题（见 [`60-technical/crawl-and-index.md`](../60-technical/crawl-and-index.md)）。
- **有展示没点击** → 标题/描述不够吸引（见 [`40-on-page/tdk.md`](../40-on-page/tdk.md)）或零点击竞争（见 [`40-on-page/beginners-onpage-myths.md`](../40-on-page/beginners-onpage-myths.md)）。
- **有点击没转化** → 落地页/产品/信任问题（见 [`30-content/eeat.md`](../30-content/eeat.md)、[`90-saas-playbook/content-production.md`](./content-production.md)）。

## 复盘节奏

- 每周看 GSC 表现，盯排名与 CTR 异常。
- 每月做一轮"内容体检"：哪些页在掉、哪些词有新机会。
- 把"真实转化数据"当最终裁判——流量好看不转化，等于没做。
