# 单页发布前检查清单（On-Page Checklist）

> 摘要：每发一个页面，按这份清单过一遍。它把前面 `40-on-page/` 的要点浓缩成可执行的发布门禁。

## 发布前逐项打勾

- [ ] **主关键词确定**，且意图与页面类型匹配（信息/商业/交易）
- [ ] **Title**：含主词、靠前、像人话、≤60 字符、全站唯一
- [ ] **Meta Description**：一句价值总结 + 点击理由、含词、≤155 字符
- [ ] **URL**：短、可读、含主词、用 `-`、稳定
- [ ] **H1** 唯一且含主词；**H2/H3** 像用户关心的问题
- [ ] 正文**自然**出现关键词，无堆砌
- [ ] 至少 1~2 处**上下文内链**到相关页（锚文本描述性）
- [ ] 必要的**出站链接**引用权威来源
- [ ] 图片压缩 + `alt` 描述
- [ ] 关键内容**不被 JS 藏住**（爬虫可读）
- [ ] 移动端排版正常、能点
- [ ] 速度达标（LCP≤2.5s 等，见 [`40-on-page/ux-core-web-vitals.md`](../40-on-page/ux-core-web-vitals.md)）
- [ ] 需要时加了 **Schema**（文章/FAQ/产品）
- [ ] 已提交/会被 **sitemap** 覆盖，GSC 能发现

## 一个小原则

清单是"下限"，不是"上限"。能通过清单只代表"不拖后腿"，能否排上去最终还是看内容价值与信任（见 [`30-content/info-gain.md`](../30-content/info-gain.md)、[`50-links/`](../50-links/_INDEX.md)）。
