# 内容生产规范（工具站 / SaaS 视角）

> 摘要：内容不是"写文章"，是"交付结果"。本节讲工具站最常见的几类页面怎么写，以及信息增量 / E-E-A-T / 内链如何在生产里落地。

## 页面类型与写法

| 类型 | 写法要点 | 承接意图 |
|---|---|---|
| **工具页** | 页面本身能用；补 SEO 文字说明工具干嘛、怎么用 | 交易/直接 |
| **博客 / 教程** | 回答一个具体问题，步骤清晰，结尾引导到工具（Last-Click 收口） | 信息 |
| **榜单页** | 真实调研、给筛选标准、每条一句真点评 | 商业 |
| **对比页** | 客观列差异维度（价格/功能/适用），注明立场 | 商业 |
| **替代页** | 说明为何找替代 + 各候选适合谁 | 商业 |

（展开见 [`30-content/content-types.md`](../30-content/content-types.md)）

## 生产流程（串起来）

1. **优先级**：先打哪些词（[`20-keyword/keyword-priority.md`](../20-keyword/keyword-priority.md)）
2. **SERP 研究**：看竞品漏了什么（[`30-content/serp-research.md`](../30-content/serp-research.md)）
3. **找信息增量**：用真实经验/数据补空缺（[`30-content/info-gain.md`](../30-content/info-gain.md)）
4. **写 + 补 E-E-A-T**：署名、来源、真实截图（[`30-content/eeat.md`](../30-content/eeat.md)）
5. **内链成图**：相关页互链，簇页回支柱页（[`40-on-page/internal-links.md`](../40-on-page/internal-links.md)）
6. **发布前过清单**（[`on-page-checklist.md`](./on-page-checklist.md)）

## 作者提醒：别新站批量上页

内容生产可以规模化，但**对新站而言，先上少量高质量页立住信任**，再逐步扩。一上来程序化生成几千页，极容易被判垃圾站、整站不收录（见 [`programmatic-seo.md`](./programmatic-seo.md)）。
