# 站内基建：从第一天搭好地基（含"整站打内页"打法）

> 摘要：本节是作者自有作战模型的核心。先讲新站地基怎么搭稳，再讲"整站打内页"这一套打法，以及作者自己的多子域架构如何天然适配。

## 一、第一天就要搭好的地基

不管你做什么站，上线前确认这几件（详见 [`60-technical/`](../60-technical/_INDEX.md)）：

- HTTPS、移动友好、基本速度。
- robots/sitemap 正确，GSC 验证并提交 sitemap。
- 重要页面从首页几步可达，有内链。
- 没有误加的 noindex / 误封的 robots。

**地基没稳就狂发内容，等于在沙地上盖楼。**

## 二、作者的核心打法：整站打内页

作者从实战中提炼的一句话逻辑：

> 谷歌的排序目标，是把"最能满足这次搜索的人"推到前面；你赢的方式，不是比大站更强，而是比大站那个**内页**更专注。

由此推出三条链路：

```
① 选空档：新词 / 供应量低的词 / 大站只用内页占位的词
        ↓
② 占位置：用一个整站（首页+二级+三级页面）去打大站的一个内页
        ↓
③ 放大：SEO 给稳定底盘 → 广告/产品放大 → 订阅或直收变现
```

### 怎么判断"能不能打"（作者自有判定标准）

- **网页供应量（搜索结果数）**：千万级 = 别碰；100~几千 = 机会窗口。
- **SERP 首页构成**：前十若多为"大站的内页"而非独立首页 → 可打；若多是成型独立站首页 → 换词。

## 三、作者的多子域架构如何天然适配

作者采用"一个 niche 一个子域"的架构（如 `howtomakemi.com` 下多个子域）。这恰好完美适配"整站打内页"：每个子域就是一个专注整站，只做一件事，正好去打大站的一个内页。

> 对独立开发者很实用：注册/划分子域的成本极低，却能获得"整站专注度"的 SEO 好处。

## 四、净增量提醒

"整站打内页"真正给到新手的新东西是**判定标准**（供应量 + SERP 首页构成），其他内容（选词 SOP、外链、验证）大多是基本功。别神话它——它是"怎么选能打的词"这一环的答案。
