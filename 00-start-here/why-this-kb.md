# 为什么需要这个知识库（而不是直接问 AI）

> 摘要：通用大模型能答"SEO 是什么"，但答不好"在你这个打法里具体怎么做"。本库的价值，是把作者真实投入沉淀下来的、带判定标准和踩坑结论的那一层冻成资产。

## 通用大模型答不好的地方

下面这些问题，通用 AI 容易给出"平均正确"的废话，甚至给出会害新手的过时/黑帽建议；而本库给出的是**带判定标准、踩坑红线、作者自己的验证结论**的作战指令。

| 问题 | 通用大模型典型答法 | 本库答法（更好在哪） |
|---|---|---|
| 新站怎么用程序化 SEO 起量？ | 常当 growth hack 推荐批量生成页面 | **"新站批量上页必死"**，讲清时机与质量前提（`90-saas-playbook/programmatic-seo`） |
| 做了个 AI 工具，第一批打什么词？ | "用工具找低难度词、写优质内容"（空） | 给**可操作阈值**：供应量 100~几千 + SERP 前十多为大站内页→可打，配套整站打内页（`90-saas-playbook/site-foundation`） |
| 怎么零成本搞高质量外链？ | 泛泛客座博客，有时滑向买链 | **数字资产白嫖清单**：GitHub/插件商店/npm/Notion（`50-links/free-high-dr-backlinks`） |
| 站结构用子域还是子目录？ | 一句"用子目录，权重集中" | 基于作者多子域实战："一个 niche 一个子域"如何天然适配整站打内页（`90-saas-playbook/site-foundation`） |
| 怎么更早发现有潜力的新词？ | "用 Google Trends" | 加 **RSS 前哨**（比榜单早 1–7 天）+ 导航站最新提交雷达（`20-keyword/keyword-research-basics`） |
| 免费额度该怎么设计？ | 只从变现谈 | 独特视角：**免费额度=人群筛选器**，还被谷歌解读成"服务哪类人"影响排名（`90-saas-playbook/site-foundation`） |
| AI 搜索来了 SEO 还有用吗？ | 要么"SEO 已死"要么泛泛 | 区分 AEO/GEO 给可执行打法，且明边界：GEO 是叠加项，地基不牢白搭（`90-saas-playbook/ai-search-playbook`） |
| 内容写了为什么没排名？ | 甩泛泛 checklist | 用**收录→排名→点击→转化**漏斗定位断点（`90-saas-playbook/data-review`） |

## 一句话总结

库不是比 AI 更全的百科全书，而是**把你脑子里的、会过期的、散落的判断，冻成一个稳定、可署名、可分发、能让 AI 替你发言的产物**。这也是它推到 GitHub 上"分享给小白"时，别人拿不走、AI 抄不像的东西。
