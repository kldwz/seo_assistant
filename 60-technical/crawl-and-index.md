# 抓取与索引（让谷歌来得了、收得进）

> 摘要：技术 SEO 的第一步——确保重要页面能被爬虫抓到、能被收录。否则前面内容做得再好也排不了。

## 关键文件与标签

| 东西 | 干嘛 | 新手要做什么 |
|---|---|---|
| **robots.txt** | 告诉爬虫哪些能抓、哪些不能 | 别误封重要目录；允许抓 CSS/JS（否则读不懂页面） |
| **sitemap.xml** | 给爬虫一张"我有哪些页"的地图 | 生成 sitemap 并提交到 GSC |
| **noindex** | 标记"别收录这页" | 只对真不想要收录的页用（如后台），别误加 |
| **canonical** | 告诉谷歌"真正的主版本是哪个" | 解决重复内容：把近似页指向权威版 |
| **301 重定向** | 旧网址永久跳转到新网址 | 改 URL 时必须做，保住权重 |

## 用 Google Search Console（GSC）

GSC 是谷歌官方免费工具，技术 SEO 的指挥中心：

- **URL 检查**：看某个页是否被收录、为什么没收录。
- **覆盖率报告**：批量看哪些页被收录、哪些被排除及原因。
- **提交 sitemap**：让谷歌更快发现你。
- **抓取统计**：看爬虫来访情况。

> 新站第一步：验证 GSC、提交 sitemap。这是"让谷歌知道你存在"的官方入口。

## 常见抓取/索引问题

- robots.txt 误封导致整站不被抓。
- 全站 JS 渲染、文字在 JS 里，爬虫读不到（尽量保证关键内容服务端渲染或可被读）。
- 重复内容没用 canonical，导致权重分散。
- 重要页没被任何链接指向（孤儿页），爬虫发现不了。
