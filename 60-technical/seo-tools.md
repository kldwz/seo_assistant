# SEO 工具清单

> 摘要：新手不必买贵工具也能起步。先掌握几个免费/必备的，再按需上付费。

## 免费且必备

| 工具 | 用来干嘛 |
|---|---|
| **Google Search Console (GSC)** | 官方：收录状态、点击数据、技术问题、提交 sitemap |
| **Google Analytics (GA4)** | 流量与用户行为分析 |
| **Google Trends** | 趋势、季节性、新词发现 |
| **PageSpeed Insights** | 测 Core Web Vitals 与速度 |
| **Rich Results Test** | 验证 Schema 结构化数据 |
| **Keyword Surfer / 浏览器插件** | 搜索量、SERP 概览（轻量） |

## 付费（进阶，按需）

| 工具 | 强项 |
|---|---|
| **Ahrefs / Semrush** | 关键词、竞品外链/排词、站点审计一体化 |
| **Screaming Frog** | 本地爬全站，查死链/重复/缺失标签 |
| **Sitebulb / 类似** | 可视化站点审计 |

## 怎么选

- **起步期**：GSC + GA + Trends + 一个免费 SERP 插件，完全够用，零成本。
- **认真做站 / 要打竞争词**：再考虑 Ahrefs 或 Semrush 之一，主要买"竞品情报 + 关键词数据"。
- **技术审计**：Screaming Frog 的一次性付费版很值。

> 工具是放大器，不是替代品。没有清晰策略，买最贵的工具也只是看更多报表。先把 [`learning-path.md`](../00-start-here/learning-path.md) 走一遍。
